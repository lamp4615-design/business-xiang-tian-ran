一杯咖啡的真實模樣，由我們共同定義

大家有發現上面專屬的 QR Code 嗎

智者曾說：「挑選咖啡，如同挑選戀人。」

每個人眼裡喜愛的模樣不同，感覺對的人也不盡相同。更別說當一杯咖啡入口，你我所感受到的酸質、甜感與香氣，往往都是獨一無二的體驗。

在經營「翔自在翔天然」的這段日子裡，我常常收到大家這樣的問題：「這支豆子喝起來是什麼感覺？」、「我怕酸，這款適合我嗎？」

每一次，我都會盡可能用最貼切的詞彙，去描述那些藏在咖啡液裡的細節。但我也深知，有時候我覺得剛好的醇厚，對你來說可能帶點驚喜的清透；我感受到的微酸，在你口中或許化作了迷人的甜感。

為了讓大家在挑選時能有更精準、更貼近大眾真實感受的參考，我決定邀請所有長期支持我們的粉絲，一起加入這場「風味共創計畫」。

⭐ 重點
把品飲的詮釋權，交還給你們

在這次釋出的新品中，大家會發現每一包產品上都印製了專屬的 QR Code 條碼。這代表著我們從單向的風味敘述，正式走向雙向的風味建構。

當你沖泡完這杯「琥珀法月」，在享受放鬆片刻的同時，只要順手掃描包裝上的條碼，就會進入一個專屬的風味評分頁面。在這裡，你可以針對五大指標——香氣、酸質、甜感、醇厚度、苦味，留下你的主觀分數。

💡 提示
為什麼建立專屬風味輪這麼重要？

因為我們想藉由各位的力量，共同創造出屬於我們的風味輪。隨著參與的人數增加，系統會自動統整大家的評價，以「眾數」萃取出大眾最真實的感受，並繪製成風味雷達圖。

這意味著，未來的每一位消費者，在購買前都能看到由無數真實顧客共同勾勒出的風味樣貌，讓大家挑選時能有更明確的依據。這比任何華麗的文案都來得真實且具參考價值。

⭐ 重點
感謝大家一路以來的支持。下一次拆開「翔自在翔天然」的包裝時，記得留下你的足跡，讓我們一起把抽象的味覺，轉化為具體的風味地圖。
